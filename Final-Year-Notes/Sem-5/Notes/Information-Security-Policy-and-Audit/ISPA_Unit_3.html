Unit 3: Cybersecurity Domains

Introduction

Cybersecurity is not just about hacking; it’s a vast field with multiple domains working together to protect assets.

Definition

Cybersecurity is the collective process of protecting computer systems, networks, and programs from digital attacks.

1. Access Control Domains

Controlling who can access what is fundamental.

A. User Access

  • Authentication: Verifying identity (Passwords, MFA, Biometrics).
  • Authorization: Granting permissions (RBAC - Role-Based Access Control).
  • Account Management: Creating, disabling, and monitoring accounts.

B. Data Access

Protecting data at rest and in motion.

  • Encryption: Scrambling data so only authorized users can read it.
  • DLP (Data Loss Prevention): Stopping sensitive data from leaving the org.

Access Methods

  • Sequential Access: Reading data in order (slower, like a tape).
  • Random Access: Jumping directly to data (faster, like a hard drive).

C. Physical Access

Real-world security.

  • Controls: Badges, Biometrics, Mantraps.
  • Surveillance: CCTV, Guards.
  • Environment: Fire suppression, HVAC.

D. Internet Access

  • Firewalls: Filter traffic.
  • VPN: Secure remote access.
  • Content Filtering: Blocking bad sites.

2. Communication Security

Email Security

Email is a primary attack vector.

  • Spam Filters: Block junk.
  • Phishing Detection: Stop credential theft.
  • Protocols: SPF, DKIM, DMARC (prevent spoofing).

Digital Signatures

A digital signature guarantees three things:

  1. Authentication: Sender is who they say they are.
  2. Integrity: Message hasn’t been changed.
  3. Non-repudiation: Sender cannot deny sending it.

3. Software Development

Building security into software, not adding it later.

SDLC (Software Development Life Cycle)

  • Requirements: Define security needs early.
  • Design: Threat modeling.
  • Coding: Secure coding standards.
  • Testing: Static and Dynamic analysis.

Coding Standards

AreaPurposeExample
NamingReadabilityuser_id instead of x

RulesSafetyAvoid goto, use safe functions

Testing Tools

  • Static Analysis: Checking code without running it (finds syntax errors, bad patterns).
  • Dynamic Analysis: Checking code while it runs (finds memory leaks, performance issues).

4. Risk Management

Risk Assessment Process

  1. Hazard Identification: What can go wrong?
  2. Risk Analysis: How likely/bad is it?
  3. Risk Control: How do we fix it?

ERM (Enterprise Risk Management)

ERM looks at risk across the entire business, including finances and operations, not just IT.

5. Governance & Education

  • Governance: Policies, laws, and decision-making structures.
  • End-user Education: Training employees to recognize Phishing and social engineering.
    • CIA Triad: Confidentiality, Integrity, Availability.

6. Threat Intelligence

Gathering data on attackers (CTI) to predict and prevent attacks.
